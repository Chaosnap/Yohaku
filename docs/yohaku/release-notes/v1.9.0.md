Yohaku 1.9：读书时不再有浮动的播放器，音乐在页脚里；音乐库启动时自动同步。

## 阅读界面

- **页脚就是音乐控制条**：阅读时书页上不再浮着播放器。点页脚的音乐按钮，整条页脚换成音乐的控制：上一首、播放 / 暂停、下一首、歌名、「当前 / 总时长」与进度滑杆、收藏、音量（点一下静音，滚轮调节）。它用的就是阅读页脚自己的按钮、标签与滑杆，看起来是同一条。再点一下音乐按钮，换回阅读的页脚。点歌名打开完整的播放面板。
- 手机上同样：页脚的音乐按钮把底部一行换成上一首、播放 / 暂停、下一首与歌名。

## 音乐库

- **浮动播放器只在音乐库里**，用于单独听歌。
- **更透明的磨砂玻璃**：播放器不再透出专辑封面的颜色，改为跟随主题的中性半透明磨砂，背后的内容隐约可见。
- **启动时自动同步**：每次打开 Yohaku 几秒后，音乐库会把同步的文件夹重新读一遍，关着 Yohaku 时新加的歌会出现，删掉的歌会消失，不用再按「立即同步」。如果某个文件夹读出来是空的（多半是外接硬盘还没接上），它的歌会先保留；按一次「立即同步」才会真正移除。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_1.9.0_windows_x64-setup.exe`（安装版）、`Yohaku_1.9.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_1.9.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_1.9.0_linux_amd64.AppImage`、`Yohaku_1.9.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_1.9.0_android_arm64.apk`（大多数手机）、`Yohaku_1.9.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_1.9.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 音乐库在启动时同步，Yohaku 开着时往文件夹里加的歌，要到下次启动或按「立即同步」才会出现。
- 桌面版的音乐与环境声音由书库窗口播放。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音。
- 还没有自己建的播放列表与随机 / 循环播放。
