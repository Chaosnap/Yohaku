Yohaku 2.1：Android 上的音乐库，也能打开系统的文件管理器了。

## 修复

- **Android 音乐库导入**：在音乐库点「+」或「导入音乐」，选「从本地文件导入」或「从文件夹导入」，现在会像书库一样打开系统的文件管理器。之前点了没有任何反应：音乐库的选择器经由 Tauri 插件的结果启动器打开，而它在 Yohaku 里一直没有弹出来；现在改用与书库相同的方式，由应用自己启动选择器，再把选好的歌曲或文件夹交回音乐库。
- 选好的歌曲与文件夹会保留长期读取权限：重启 Yohaku 后照样能播放，同步的文件夹照样在启动时自动同步。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_2.1.0_windows_x64-setup.exe`（安装版）、`Yohaku_2.1.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_2.1.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_2.1.0_linux_amd64.AppImage`、`Yohaku_2.1.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_2.1.0_android_arm64.apk`（大多数手机）、`Yohaku_2.1.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_2.1.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 音乐库在启动时同步，Yohaku 开着时往文件夹里加的歌，要到下次启动或按「立即同步」才会出现。
- 桌面版的音乐与环境声音由书库窗口播放。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音。
- 还没有自己建的播放列表与随机 / 循环播放。
