Yohaku 的第四个预览版：音乐播放器的第一版。

## 新功能：音乐

书库右上角菜单 →「音乐」。

- **你自己的音乐**：添加任意音频文件（FLAC、MP3、AAC / M4A、WAV、Ogg 等），按添加的顺序成为播放队列；轻点一首从它开始播放，可以上一首、下一首、拖动进度。
- **后台播放（Android）**：音乐在系统的媒体服务中播放，锁屏、切换到其他应用后继续；通知栏、锁屏与蓝牙耳机的按键都能控制；拔出耳机或来电时暂停。
- **环境声音**：再添加最多三个声音（雨声、风声或任何录音），它们在音乐旁循环播放，各自调节音量，随音乐一起播放和暂停。
- **睡眠定时**：15 到 90 分钟后，用 30 秒把音乐和环境声音慢慢调轻，然后暂停。
- 桌面版暂时在应用窗口内播放（关闭窗口即停止），原生的桌面音频引擎在之后的版本中加入。

已经加入的曲目与环境声会被记住，下次打开仍在。音乐文件只是被引用，不会被复制或修改。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_0.0.4_windows_x64-setup.exe`（安装版）、`Yohaku_0.0.4_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_0.0.4_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_0.0.4_linux_amd64.AppImage`、`Yohaku_0.0.4_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_0.0.4_android_arm64.apk`（大多数手机）、`Yohaku_0.0.4_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_0.0.4_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 曲目名称取自文件名，还不读取标签与封面；专辑、艺术家与唱片柜在之后的版本中加入。
- 只有环境声音、没有音乐时不能单独播放环境声音。
- 图标是占位图标；深链接仍使用 `readest://`。
