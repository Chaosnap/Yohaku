Yohaku 2.2：在 Android 上，音乐库与白噪音终于真正可用。

## Android：音乐库与环境声音

在 Android 上，音乐库与环境声音此前几乎都不工作：「从本地文件导入」「从文件夹导入」点了没有反应，环境声音不响，还会弹出写着「[object Object]」的错误，有时在导入书籍时也会出现。2.1 改了选择器的启动方式，却没有找到真正的原因。

原因是：Tauri 在 Android 上按 camelCase 的名字调用插件的方法（`pick_folder` 找的是 `pickFolder`），而 Yohaku 音频插件的方法名用的是下划线，Android 上的 15 个调用里有 11 个找不到方法。改名之后：

- 「从本地文件导入」「从文件夹导入」会像导入书籍一样打开系统的文件管理器，选好的歌曲与文件夹会保留长期读取权限；
- 环境声音与五个场景可以播放；
- 歌曲的扫描与启动时同步、播放队列、拖动进度、音量、歌词与睡眠定时都能用了；
- 导入书籍等操作时偶尔弹出的「[object Object]」也不会再出现；以后出错时，提示会写明具体原因。

另外加了一项自动检查：Android 引擎调用的每一个命令，都必须在插件里找得到对应的方法，以后不会再这样悄悄失效。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_2.2.0_windows_x64-setup.exe`（安装版）、`Yohaku_2.2.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_2.2.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_2.2.0_linux_amd64.AppImage`、`Yohaku_2.2.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_2.2.0_android_arm64.apk`（大多数手机）、`Yohaku_2.2.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_2.2.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 音乐库在启动时同步，Yohaku 开着时往文件夹里加的歌，要到下次启动或按「立即同步」才会出现。
- 桌面版的音乐与环境声音由书库窗口播放。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音。
- 还没有自己建的播放列表与随机 / 循环播放。
