Yohaku 1.6：边读边听更顺手，有了收藏和会流动的歌词。

## 朗读

- **不再有浮在页面上的朗读播放器**：朗读的控制都放进右上角的朗读面板，样式与音乐面板一致：书的封面、书名、章节与本章剩余时间，上一句、播放 / 暂停、下一句，左边停止，右边打开完整的朗读播放器（语速、声音、定时都在那里）；有定时关闭时显示倒计时。环境声场景仍在这个面板里。
- 「精简」样式的朗读播放器也不再在正文底部留白，设置里的「播放器样式」随之去掉。

## 阅读时听歌

- **侧栏的「歌曲」**：左侧栏目录按钮的右边多了一个「歌曲」标签。上方是正在播放的歌曲（播放 / 暂停、下一首），下面可以在四个视图之间切换：
  - **队列**：正在播放的这一组歌，点一首就跳过去；
  - **全部**：音乐库里的所有歌曲；
  - **收藏**：加了心形的歌曲；
  - **歌词**：像 Apple Music 那样的实时歌词。正在唱的一行明亮、放大，其余各行变淡并按距离轻微模糊，整段歌词一行接一行地流动；有逐字时间的歌词会一个字一个字地填色；遇到间奏显示三个跳动的点。点任意一行从那里开始播放，用滚轮或手指可以前后翻看，片刻后自动回到正在唱的位置。
- **歌词从哪里来**：歌曲旁边同名的 `.lrc` 文件（例如 `雪国.flac` 旁的 `雪国.lrc`），或者歌曲标签里的歌词。支持多个时间标签、`[offset]`、逐字时间（`<mm:ss.xx>`）和同一时间的翻译行（显示在原文下方）；GBK 编码的中文歌词文件也能正确读取。Android 上 `.lrc` 文件需要在同步的文件夹里，逐个导入的歌曲只读取标签里的歌词。
- **小播放器**：改成磨砂半透明的玻璃质感，页面透过它隐约可见；加了收藏的心形和音量（桌面，点喇叭图标调节，滚轮也可以），音量会被记住。它随工具栏出现，几秒后自动隐去；换歌时会出来几秒，告诉你现在是哪一首。

## 音乐库

- **收藏**：每首歌旁都有心形图标，点一下加入收藏，再点一下取消；音乐库多了「收藏」标签，最近收藏的排在最前。小播放器、播放面板和侧栏里也能收藏。
- **播放面板**：可以收藏，也可以把封面换成歌词。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_1.6.0_windows_x64-setup.exe`（安装版）、`Yohaku_1.6.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_1.6.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_1.6.0_linux_amd64.AppImage`、`Yohaku_1.6.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_1.6.0_android_arm64.apk`（大多数手机）、`Yohaku_1.6.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_1.6.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 桌面版的音乐与环境声音由书库窗口播放（在独立窗口中读书时，阅读窗口的按钮、侧栏与快捷键控制的也是它）。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音；同时播放音乐时不受影响。
- 还没有自己建的播放列表与随机 / 循环播放。
- 图标是占位图标；深链接仍使用 `readest://`。
