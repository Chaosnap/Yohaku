Yohaku 1.5：朗读和音乐换了位置，环境声音可以单独播放，音乐库多了艺术家和详情页。

## 阅读界面

- **右上角是朗读**：原来的音乐按钮换成朗读按钮（耳机图标）。点开可以从当前页开始朗读，或者停止朗读，环境声场景也在这里。快捷键 **T** 同样可以开始或停止朗读。
- **页脚是音乐**：页脚原来的「朗读」按钮换成「音乐」按钮。点一下，页脚上方浮出音乐小播放器，样式与朗读的小播放器一致：封面、歌名、艺术家与剩余时间，上一首、播放 / 暂停、下一首，右侧的 × 停止音乐；底边的细线是播放进度。点歌名打开完整的播放面板。小播放器随工具栏出现和隐去，音乐开始播放时会自动出现；同时朗读时，音乐小播放器在朗读小播放器上方。快捷键 **M**、**,**、**.** 不变。
- **笔记本是一张卡片**：桌面上右侧的笔记本不再贴着窗口边缘，而是浮在页面旁边的圆角卡片。

## 环境声音

- **可以单独播放了**：不需要先放音乐。可以只开环境声音，可以边听朗读边开，也可以与音乐叠加。
- **名称前有符号**：雨云、太阳、海边落日、鱼、雪花……一眼就知道是哪种声音。
- 每次打开 Yohaku，环境声音都从静音开始，不会自己响起来。

## 音乐库

- **艺术家**：新增「艺术家」分类。点开一位艺术家，可以看到这位艺术家的专辑与全部歌曲，一键播放。
- **详情**：专辑卡片右下角和每首歌的末尾多了 ⓘ，点开是与书籍详情相同样式的详情页：艺术家、专辑、曲目、碟片、时长、年份、流派、格式、比特率、采样率、文件大小、加入日期与文件位置。逐个导入的歌曲可以在这里从音乐库移除（文件本身不会被删除）。
- **添加单曲**：专辑网格的最后一格是「+」，歌曲列表的最后一行是「导入文件」，和书库添加书籍一样顺手。
- **底部播放器**：音乐库底部的播放条换成与阅读界面相同的浮动小播放器，× 可以把它收起。

## 升级说明

- 年份、流派、比特率、采样率与文件大小是这一版开始读取的信息。之前加入的歌曲，请在音乐库右上角按一次「立即同步」，逐个导入的文件也会一起重新读取。
- 1.0 中选择的环境声音不会自动恢复，请重新选择场景。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_1.5.0_windows_x64-setup.exe`（安装版）、`Yohaku_1.5.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_1.5.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_1.5.0_linux_amd64.AppImage`、`Yohaku_1.5.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_1.5.0_android_arm64.apk`（大多数手机）、`Yohaku_1.5.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_1.5.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 桌面版的音乐与环境声音由书库窗口播放（在独立窗口中读书时，阅读窗口的按钮与快捷键控制的也是它）。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。原生的桌面音频引擎在之后的版本中加入。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音；同时播放音乐时不受影响。
- 还没有播放列表视图与随机 / 循环播放。
- 图标是占位图标；深链接仍使用 `readest://`。
