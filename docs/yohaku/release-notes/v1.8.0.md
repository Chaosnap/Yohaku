Yohaku 1.8：重新设计的音乐播放器，用完就隐去。

## 音乐播放器

- **重新设计**：磨砂玻璃卡片透出当前专辑封面的颜色；暂停时封面轻轻缩回，播放时舒展开；进度是播放按钮外的一圈细环，播放器底边不再有进度线。窄屏上省去「上一首」，给歌名多留些位置。
- **用完就隐去**：播放器随阅读界面的工具栏出现；打开、换歌、播放或暂停以及每次操作后停留 5 秒再隐去，暂停时也一样。指针在播放器上移动时它会一直留着。

## 阅读侧栏

- **「歌词」是单独的标签**，在「歌曲」与「批注」之间（麦克风图标）；「歌曲」标签里是队列、全部、收藏。
- 「歌曲」与「歌词」标签不再在顶部显示书籍卡片。
- 底部的标签按钮等宽排列，侧栏在默认宽度下也不会有按钮超出。

## 朗读

- 关闭书（回到书库）时朗读随之停止，书库里不再出现朗读的浮动条。朗读只在阅读界面右上角的朗读面板里控制。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_1.8.0_windows_x64-setup.exe`（安装版）、`Yohaku_1.8.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_1.8.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_1.8.0_linux_amd64.AppImage`、`Yohaku_1.8.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_1.8.0_android_arm64.apk`（大多数手机）、`Yohaku_1.8.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_1.8.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 估算的逐字时间只是近似：歌手在一行里时快时慢时，填色会与歌声略有出入；带逐字时间的歌词不受影响。
- 桌面版的音乐与环境声音由书库窗口播放。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音。
- 还没有自己建的播放列表与随机 / 循环播放。
