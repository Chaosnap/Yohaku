Yohaku 1.7：歌词更像在唱。

## 歌词

- **每一行都逐字填色**：以前只有带逐字时间的歌词才会一个字一个字地亮起来，现在只有整行时间的普通 `.lrc` 也会：中文、日文、韩文按字，其他语言按词，在这一行与下一行之间按字数分配时间；遇到长间奏也不会慢得拖沓。
- **柔和的光晕**：深色主题下，唱过的字带一圈淡淡的光。
- **歌词会呼吸**：播放时整段歌词随音乐缓慢地上下浮动，暂停时静止。
- 系统开启「减少动态效果」或使用电子墨水屏时，这些动画都会关闭。

光晕与呼吸的做法借鉴了 [Folia](https://github.com/chthollyphile/folia-major)（AGPL-3.0），代码由 Yohaku 自行编写。光晕的大小始终不变：Folia 发现在 Linux 的 Chromium 上逐帧改变光晕会让字形缓存不断增长，Yohaku 的 Linux 版同样基于 Chromium。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_1.7.0_windows_x64-setup.exe`（安装版）、`Yohaku_1.7.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_1.7.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_1.7.0_linux_amd64.AppImage`、`Yohaku_1.7.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_1.7.0_android_arm64.apk`（大多数手机）、`Yohaku_1.7.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_1.7.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 估算的逐字时间只是近似：歌手在一行里时快时慢时，填色会与歌声略有出入；带逐字时间的歌词不受影响。
- 桌面版的音乐与环境声音由书库窗口播放。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音。
- 还没有自己建的播放列表与随机 / 循环播放。
