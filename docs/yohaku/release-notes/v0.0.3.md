Yohaku 的第三个预览版：移除登录页面，并带来 Phase 1「阅读核心」的第一批改进。

## 变化

- **移除登录与账户页面。** Yohaku 没有账户：登录、账户、设备配对与「发送到 Readest」页面不再出现，任何入口（包括深链接）都会直接回到书库。v0.0.2 已经移除了书本下方的「上传到云端」按钮和其他通往登录页的入口。
- **三个阅读主题**：暖纸、月白、墨夜（「设置 → 主题」，在「默认」之后），浅色与深色两种模式都有。
- **按语言排版**：首次启动时按界面语言设定行距、段距、首行缩进与两端对齐（中文缩进两字、日文缩进一字且段间无空行、英文以段距分段）；打开其他语言的书时，这本书自动使用它自己语言的排版，你在全局改过的设置仍然优先。
- **漫画阅读方向**：ComicInfo.xml 标记为从右到左（`Manga=YesAndRightToLeft`）的漫画自动从右到左翻页；「设置 → 版式 → 漫画 → 默认从右到左」让没有标记方向的漫画也从右到左阅读。
- **朗读默认不联网**：开始朗读时不再连接微软的 Edge 语音或 Readest 的云端语音，默认使用系统语音；需要微软在线语音时，在「设置 → 朗读 → 语音 → 在线语音」中开启（朗读的文字会发送给微软）。
- **不再连接 Readest 的服务器**：需要 Readest 账户的 DeepL 翻译已移除；仍会调用 Readest 服务器的少数功能（如在线检索书籍元数据）现在直接失败，不会把数据发给 Readest。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_0.0.3_windows_x64-setup.exe`（安装版）、`Yohaku_0.0.3_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_0.0.3_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_0.0.3_linux_amd64.AppImage`、`Yohaku_0.0.3_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_0.0.3_android_arm64.apk`（大多数手机）、`Yohaku_0.0.3_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_0.0.3_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 图标是占位图标，正式图标在暗室（Phase 3）中完成。
- 深链接仍使用 `readest://`；同时安装了 Readest 时，系统可能会询问由哪个应用打开。
- 在线检索书籍元数据（书籍详情 → 编辑 → 自动检索）暂时不可用，之后改为直接访问公开的书目服务。
- 已经在旧版本中使用过的设置不会自动改成新的排版默认值；可以在「设置 → 版式」中重置。
