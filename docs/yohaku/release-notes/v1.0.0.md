Yohaku 1.0：书库之外，有了自己的音乐库。

## 书籍与音乐

书库顶部、搜索框左侧多了「书籍 / 音乐」切换，一键在书库与音乐库之间来回。音乐不再藏在菜单里。

## 音乐库

- **两种加入方式**：「同步文件夹」把一个文件夹（连同其中所有子文件夹）里的歌曲都放进音乐库，可以同步多个文件夹，之后按「立即同步」就能收进新加的歌、去掉已删除的歌；「导入文件」一首一首地加入。音乐文件只被引用，不会被复制或修改。
- **标签与封面**：读取歌曲的标题、艺术家、专辑、曲目号与内嵌封面（FLAC、MP3、AAC / M4A、ALAC、Ogg、Opus、WAV、AIFF 等）。
- **像书库一样浏览**：「专辑」以封面网格排列，点开是整张专辑的曲目；「歌曲」列出全部歌曲；「文件夹」管理同步的文件夹与导入的文件。顶部可以按标题、艺术家或专辑搜索。
- **播放**：底部的播放条显示正在播放的歌曲，点开是播放面板：进度、上一首、下一首、睡眠定时（15 到 90 分钟后用 30 秒慢慢调轻并暂停）。
- **Android 后台播放**：锁屏、切到其他应用后继续播放；锁屏与通知栏显示歌名、艺术家与封面，蓝牙耳机按键可以控制。

## 环境声音

十种环境声音全部由 Yohaku 自己合成，不需要添加任何文件：雨、屋檐雨、风、海浪、壁炉、森林、蝉鸣、夜晚虫鸣、溪流、唱片底噪。可以一键选择「雨夜」「夏日午后」「黄昏海边」「夜间水族馆」「冬日书房」五个场景，也可以逐个打开并调节音量。环境声音随音乐一起播放和暂停。

## 边读边听

- 阅读界面右上角新增音乐按钮：正在播放的歌曲、播放控制与环境声场景，不用离开书页。
- 快捷键：**M** 播放 / 暂停，**,** 上一首，**.** 下一首。可以在「设置 → 行为 → 键盘快捷键」中修改。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_1.0.0_windows_x64-setup.exe`（安装版）、`Yohaku_1.0.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_1.0.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_1.0.0_linux_amd64.AppImage`、`Yohaku_1.0.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_1.0.0_android_arm64.apk`（大多数手机）、`Yohaku_1.0.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_1.0.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 桌面版的音乐由书库窗口播放（在独立窗口中读书时，阅读窗口的音乐按钮与快捷键控制的也是它）。macOS 关闭书库窗口只是隐藏，音乐继续；Windows 与 Linux 上关闭书库窗口会停止音乐。原生的桌面音频引擎在之后的版本中加入。
- 环境声音只随音乐播放，还不能单独播放。
- 还没有艺术家、播放列表视图与随机 / 循环播放。
- 图标是占位图标；深链接仍使用 `readest://`。
