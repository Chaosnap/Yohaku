Yohaku 的第一个预览版，对应 Phase 0「基础建立」。它以 [Readest](https://github.com/readest/readest) v0.12.16（AGPL-3.0）为基础，目前只有阅读功能；音乐、环境声音与暗室等空间会在之后的版本中加入，计划见[路线图](https://github.com/Chaosnap/Yohaku/blob/main/docs/yohaku/03-roadmap.md)。

## 这一版包含

- 名称、图标与应用标识改为 Yohaku（`io.github.chaosnap.yohaku`），可以与 Readest 同时安装。
- 离线使用：没有账户、云同步、付费与遥测，不检查更新，不加载在线字体。OPDS 书源、WebDAV / S3 / KOReader 同步等需要联网的功能，只在你主动配置后才联网。
- 保留 Readest 的全部阅读功能：EPUB、MOBI / AZW3、FB2、CBZ、PDF、TXT、Markdown；目录、搜索、高亮与批注、书签、朗读、词典，以及阅读进度保存。
- 关于页注明基于 Readest，并附本仓库的源码地址。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_0.0.1_windows_x64-setup.exe`（安装版）、`Yohaku_0.0.1_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_0.0.1_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_0.0.1_linux_amd64.AppImage`、`Yohaku_0.0.1_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_0.0.1_android_arm64.apk`（大多数手机）、`Yohaku_0.0.1_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上 |

`Yohaku_0.0.1_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 图标是占位图标，正式图标在暗室（Phase 3）中完成。
- 深链接仍使用 `readest://`；同时安装了 Readest 时，系统可能会询问由哪个应用打开。
- 在线翻译、在线朗读（Edge TTS）与 AI 助手的入口仍然可见，使用时会连接相应的在线服务；计划在 v0.1.0 中默认隐藏。
