Yohaku 的第二个预览版：移除仍然指向 Readest 账户的云端入口。阅读功能与 [v0.0.1](https://github.com/Chaosnap/Yohaku/releases/tag/v0.0.1) 相同。

## 变化

- 移除书本下方的「上传到云端」按钮。它属于 Readest Cloud，在 Yohaku 中按下只会跳到 Readest 的登录页。
- 书籍的右键菜单、书籍详情和阅读器菜单不再提供需要 Readest 账户的「上传」「下载」「分享书籍」；手机上的下拉刷新也不再跳到登录页。
- 在「设置 → 集成」中配置了 WebDAV、S3 等文件同步时，只存在于服务器上的书会显示「下载」按钮，不需要登录。
- 没有配置任何同步服务时，阅读器菜单不再显示「从未同步」一行，书籍详情中只有一个「删除」。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_0.0.2_windows_x64-setup.exe`（安装版）、`Yohaku_0.0.2_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_0.0.2_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_0.0.2_linux_amd64.AppImage`、`Yohaku_0.0.2_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_0.0.2_android_arm64.apk`（大多数手机）、`Yohaku_0.0.2_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装 v0.0.1 |

`Yohaku_0.0.2_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 图标是占位图标，正式图标在暗室（Phase 3）中完成。
- 深链接仍使用 `readest://`；同时安装了 Readest 时，系统可能会询问由哪个应用打开。
- 在线翻译、在线朗读（Edge TTS）与 AI 助手的入口仍然可见，使用时会连接相应的在线服务；其中 DeepL 需要 Readest 账户，在 Yohaku 中不可用。计划在 v0.1.0 中默认隐藏。
