Yohaku 2.0：在文字与声音之间，留一处属于自己的空白。

## 新图标「留白」

Yohaku 有了自己的图标：一本摊开的书，左页是字，右页几乎是空的，只落着一个朱红的音符。文字、声音，和它们之间的那一处空白，就是「余白」。夜色的底，纸色的书，一点朱红。桌面、Android 启动器与启动画面都换成了新图标；Android 13 起的主题图标是同一本书的单色剪影。

## 音乐库

- **和书库一样的导入菜单**：音乐库右上角的「+」与空音乐库页的「导入音乐」按钮，打开与书库相同的菜单：「从本地文件导入」逐首加入歌曲，Android 上会打开系统的文件管理器；「从文件夹导入」加入一个文件夹，之后保持同步。
- **队列更像队列**：阅读侧栏的「队列」只列出正在播放和接下来的歌，不再从头列出整个歌单。从「全部」「收藏」或音乐库的歌曲列表点一首歌，排进队列的是这首和它后面的歌；点专辑里的歌，仍保留整张专辑的顺序，「上一首」可以回到前一轨。

## 阅读界面

- **竖着的音量条**：页脚音乐控制条上的音量按钮，会在上方立起一条竖着的音量滑杆，用的是页脚同样的滑杆与配色：上面是音量数字，下面是静音按钮。调好后指针离开（或手指抬起）片刻，它自己收起；点别处立即收起；滚轮在按钮上也能调。手机上的音乐控制条也有。
- **歌词标签换了图标**：侧栏的「歌词」不再用麦克风，换成一个带音符的歌词气泡。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `Yohaku_2.0.0_windows_x64-setup.exe`（安装版）、`Yohaku_2.0.0_windows_x64-portable.exe`（便携版） | 可能出现 SmartScreen 提示，选择「更多信息 → 仍要运行」 |
| macOS | `Yohaku_2.0.0_macos_universal.dmg` | 未经 Apple 公证；首次打开被拦截时，到「系统设置 → 隐私与安全性」点击「仍要打开」 |
| Linux | `Yohaku_2.0.0_linux_amd64.AppImage`、`Yohaku_2.0.0_linux_amd64.deb` | x86_64 |
| Android | `Yohaku_2.0.0_android_arm64.apk`（大多数手机）、`Yohaku_2.0.0_android_armv7.apk`（较旧的 32 位手机） | Android 8.0 及以上；可以直接覆盖安装之前的版本 |

`Yohaku_2.0.0_android_googleplay.aab` 供 Google Play 使用，不能直接安装。下载后可以用 `SHA256SUMS.txt` 校验文件；每个文件都附有 GitHub 的构建来源证明。

## 已知问题

- 系统可能会缓存旧图标：macOS 上如果程序坞仍显示旧图标，重新打开一次 Yohaku 即可；Android 上个别启动器需要重新添加到桌面。
- 音乐库在启动时同步，Yohaku 开着时往文件夹里加的歌，要到下次启动或按「立即同步」才会出现。
- 桌面版的音乐与环境声音由书库窗口播放。macOS 关闭书库窗口只是隐藏，声音继续；Windows 与 Linux 上关闭书库窗口会停止声音。
- Android 上只播放环境声音（没有音乐）时，Yohaku 切到后台一段时间后，系统可能会停止声音。
- 还没有自己建的播放列表与随机 / 循环播放。
