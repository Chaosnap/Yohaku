# 快捷键

在桌面上读书，几乎每件事都有快捷键。阅读时按 <kbd>Shift</kbd> + <kbd>?</kbd>，Yohaku 会列出全部快捷键。

::: tip macOS
下表中的 <kbd>Ctrl</kbd> 在 macOS 上是 <kbd>⌘</kbd>，<kbd>Alt</kbd> 是 <kbd>⌥</kbd>。
:::

## 音乐

Yohaku 加上的三个键，读书时不用离开键盘就能控制音乐：

| 按键 | 作用 |
|---|---|
| <kbd>M</kbd> | 播放 / 暂停音乐 |
| <kbd>.</kbd> | 下一首 |
| <kbd>,</kbd> | 上一首 |

## 翻页与跳转

| 按键 | 作用 |
|---|---|
| <kbd>←</kbd> / <kbd>H</kbd> | 向左 / 上一页 |
| <kbd>→</kbd> / <kbd>L</kbd> / <kbd>Space</kbd> | 向右 / 下一页 |
| <kbd>↑</kbd> / <kbd>K</kbd>、<kbd>↓</kbd> / <kbd>J</kbd> | 向上、向下 |
| <kbd>PageUp</kbd>、<kbd>PageDown</kbd> | 上一页、下一页 |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd> | 上一章、下一章 |
| <kbd>U</kbd>、<kbd>D</kbd> | 向上、向下滚动半页 |
| <kbd>Home</kbd>、<kbd>End</kbd> | 书籍开头、书籍结尾 |
| <kbd>Shift</kbd> + <kbd>H</kbd>、<kbd>Shift</kbd> + <kbd>L</kbd> | 返回、前进 |

## 阅读界面

| 按键 | 作用 |
|---|---|
| <kbd>S</kbd> | 显示 / 隐藏侧栏 |
| <kbd>Ctrl</kbd> + <kbd>Tab</kbd> | 切换侧栏标签 |
| <kbd>N</kbd> | 显示 / 隐藏笔记本 |
| <kbd>Enter</kbd> | 显示 / 隐藏工具栏 |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | 在书中搜索 |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | 加上 / 去掉书签 |
| <kbd>Shift</kbd> + <kbd>J</kbd> | 切换滚动模式 |
| <kbd>Shift</kbd> + <kbd>A</kbd> | 切换自动滚动 |
| <kbd>Shift</kbd> + <kbd>P</kbd> | 切换段落模式 |
| <kbd>Shift</kbd> + <kbd>V</kbd> | 快读模式 |
| <kbd>Ctrl</kbd> + <kbd>=</kbd>、<kbd>Ctrl</kbd> + <kbd>-</kbd>、<kbd>Ctrl</kbd> + <kbd>0</kbd> | 放大、缩小、重置缩放 |
| <kbd>Shift</kbd> + <kbd>F</kbd> 或 <kbd>Ctrl</kbd> + <kbd>,</kbd> | 打开设置 |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | 打开命令面板 |

## 选中文字以后

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>H</kbd> | 划线 |
| <kbd>Ctrl</kbd> + <kbd>U</kbd> | 下划线 |
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | 添加笔记 |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | 保存笔记 |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | 复制 |
| <kbd>Ctrl</kbd> + <kbd>T</kbd> | 翻译 |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | 查词典 |
| <kbd>Ctrl</kbd> + <kbd>R</kbd> | 朗读选中的文字 |

## 朗读

| 按键 | 作用 |
|---|---|
| <kbd>T</kbd> | 打开 / 关闭朗读 |
| <kbd>Space</kbd> | 朗读时：播放 / 暂停 |
| <kbd>Ctrl</kbd> + <kbd>]</kbd>、<kbd>Ctrl</kbd> + <kbd>[</kbd> | 下一句、上一句 |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>}</kbd>、<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>{</kbd> | 下一段、上一段 |
| <kbd>Shift</kbd> + <kbd>M</kbd> | 高亮当前句子 |

## 窗口与应用

| 按键 | 作用 |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | 打开书库 |
| <kbd>F11</kbd> | 全屏 |
| <kbd>Shift</kbd> + <kbd>R</kbd> | 重新加载页面 |
| <kbd>Esc</kbd> | 关闭 |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | 关闭窗口 |
| <kbd>Ctrl</kbd> + <kbd>Q</kbd> | 退出 Yohaku |
