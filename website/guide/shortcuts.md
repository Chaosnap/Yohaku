# Shortcuts

Reading on the desktop, almost everything has a shortcut. Press <kbd>Shift</kbd> + <kbd>?</kbd> while reading and Yohaku lists them all.

::: tip macOS
On macOS, <kbd>Ctrl</kbd> in these tables is <kbd>⌘</kbd>, and <kbd>Alt</kbd> is <kbd>⌥</kbd>.
:::

## Music

Yohaku's three keys control the music without leaving the keyboard:

| Key | Does |
|---|---|
| <kbd>M</kbd> | Play / pause music |
| <kbd>.</kbd> | Next song |
| <kbd>,</kbd> | Previous song |

## Turning pages and moving around

| Key | Does |
|---|---|
| <kbd>←</kbd> / <kbd>H</kbd> | Left / previous page |
| <kbd>→</kbd> / <kbd>L</kbd> / <kbd>Space</kbd> | Right / next page |
| <kbd>↑</kbd> / <kbd>K</kbd>, <kbd>↓</kbd> / <kbd>J</kbd> | Up, down |
| <kbd>PageUp</kbd>, <kbd>PageDown</kbd> | Previous page, next page |
| <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd> | Previous chapter, next chapter |
| <kbd>U</kbd>, <kbd>D</kbd> | Scroll half a page up, down |
| <kbd>Home</kbd>, <kbd>End</kbd> | Start of the book, end of the book |
| <kbd>Shift</kbd> + <kbd>H</kbd>, <kbd>Shift</kbd> + <kbd>L</kbd> | Back, forward |

## The reader

| Key | Does |
|---|---|
| <kbd>S</kbd> | Show / hide the sidebar |
| <kbd>Ctrl</kbd> + <kbd>Tab</kbd> | Switch sidebar tabs |
| <kbd>N</kbd> | Show / hide the notebook |
| <kbd>Enter</kbd> | Show / hide the toolbar |
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | Search in the book |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | Add / remove a bookmark |
| <kbd>Shift</kbd> + <kbd>J</kbd> | Toggle scroll mode |
| <kbd>Shift</kbd> + <kbd>A</kbd> | Toggle auto scroll |
| <kbd>Shift</kbd> + <kbd>P</kbd> | Toggle paragraph mode |
| <kbd>Shift</kbd> + <kbd>V</kbd> | Speed reading mode |
| <kbd>Ctrl</kbd> + <kbd>=</kbd>, <kbd>Ctrl</kbd> + <kbd>-</kbd>, <kbd>Ctrl</kbd> + <kbd>0</kbd> | Zoom in, zoom out, reset zoom |
| <kbd>Shift</kbd> + <kbd>F</kbd> or <kbd>Ctrl</kbd> + <kbd>,</kbd> | Open settings |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> | Open the command palette |

## With text selected

| Key | Does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>H</kbd> | Highlight |
| <kbd>Ctrl</kbd> + <kbd>U</kbd> | Underline |
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | Add a note |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Save the note |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | Copy |
| <kbd>Ctrl</kbd> + <kbd>T</kbd> | Translate |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | Look up in the dictionary |
| <kbd>Ctrl</kbd> + <kbd>R</kbd> | Read the selection aloud |

## Read aloud

| Key | Does |
|---|---|
| <kbd>T</kbd> | Start / stop reading aloud |
| <kbd>Space</kbd> | While reading aloud: play / pause |
| <kbd>Ctrl</kbd> + <kbd>]</kbd>, <kbd>Ctrl</kbd> + <kbd>[</kbd> | Next sentence, previous sentence |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>}</kbd>, <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>{</kbd> | Next paragraph, previous paragraph |
| <kbd>Shift</kbd> + <kbd>M</kbd> | Highlight the current sentence |

## Windows and the app

| Key | Does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | Open the library |
| <kbd>F11</kbd> | Full screen |
| <kbd>Shift</kbd> + <kbd>R</kbd> | Reload the page |
| <kbd>Esc</kbd> | Close |
| <kbd>Ctrl</kbd> + <kbd>W</kbd> | Close the window |
| <kbd>Ctrl</kbd> + <kbd>Q</kbd> | Quit Yohaku |
